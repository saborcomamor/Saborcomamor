# Sabor com Amor — pacote de especificações por tela e seção

Este pacote é documentação modular de handoff. Não é um aplicativo pronto nem substitui o guia mestre.

`paginas/`: um briefing independente por página do site.
`secoes_home/`: uma especificação independente para cada seção da homepage.
`seguranca/`: requisitos prioritários de privacidade e segurança.
`arquitetura/`: contrato de implementação para não concentrar tudo em um arquivo.
`conteudo/`: textos-base da marca.

A implementação deve ter um arquivo físico próprio para **cada página e cada seção** e conservar animações complexas isoladas.

`secoes_internas/`: componentes independentes de serviços, galeria, história, orçamento e painel.
