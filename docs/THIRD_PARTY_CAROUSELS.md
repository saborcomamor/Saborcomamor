# Carrosséis adaptados para o Sabor com Amor
Foram utilizados exclusivamente os **padrões de interação** dos ZIPs enviados pelo proprietário do site:
- **Tilted Carousel** — navegação opcional por miniaturas inclinadas do portfólio (`components/gallery/GalleryTiltedPicker.tsx`).
  Projeto original: https://codepen.io/vii120/pen/VYmmdMK.
- **File Drawer Carousel** — animação de fotografias em gaveta na Home (`components/home/CurvedEventGallery.tsx`).
  Projeto original: https://codepen.io/vii120/pen/JoEBvya.
